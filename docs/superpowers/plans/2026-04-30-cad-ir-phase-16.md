# CAD IR Phase 16 — 3D-print specific rules

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development.

**Goal:** Two new manufacturing rules that fire only when `process === "print_3d"`. `mfg.print-3d-min-wall` enforces a per-material minimum wall thickness (FDM is more forgiving than SLA on the high end; tighter on min). `mfg.print-3d-bed-size` warns when the part exceeds typical desktop printer bed sizes (220×220×250mm = average i3-class).

## Tasks

### Task 1: `mfg.print-3d-min-wall` rule

Per-material thresholds (extend Material type or use a constant map). FDM-style materials (PLA/PETG/ABS) → 0.8mm minimum. SLA-style not in catalog yet → defer. PETG → 1.0mm (slightly tighter due to oozing).

`convex/cad/validate/rules/print3dMinWall.ts`:

```ts
import type { ResolvedIr } from "../../resolve/resolveIr";
import type { CadIr } from "../../ir/types";
import type { Violation } from "../../../plugins/types";

const MIN_WALL_BY_MATERIAL: Record<string, number> = {
  "pla": 0.8,
  "petg": 1.0,
  "abs": 0.8,
  "aluminum-6061": 2.0,    // generic fallback for non-print materials
  "steel-1018": 2.0,
  "stainless-304": 2.0,
};

const FALLBACK = 0.8;

export function print3dMinWall(resolved: ResolvedIr, original: CadIr): Violation[] {
  if (original.process !== "print_3d") return [];
  const matName = original.material ?? "pla";
  const minWall = MIN_WALL_BY_MATERIAL[matName] ?? FALLBACK;

  const out: Violation[] = [];
  for (const f of resolved.features) {
    if (f.kind !== "extrude" || f.suppressed) continue;
    const distance = f.distance as number;
    if (distance < minWall) {
      out.push({
        ruleId: "mfg.print-3d-min-wall",
        severity: "error",
        message: `Extrude "${f.id}" thickness ${distance}mm is below the ${minWall}mm minimum for 3D-printed ${matName}.`,
        agentMessage: `For 3D printing in ${matName}, walls thinner than ${minWall}mm warp or fail to bridge. Increase the extrude distance for "${f.id}" or change material/process.`,
        location: { kind: "feature", id: f.id },
      });
    }
  }
  return out;
}
```

Tests (3): under-min for PLA, under-min for PETG (different threshold), passes when at-min.

Commit: `feat(cad-ir): mfg.print-3d-min-wall — per-material minimum thickness for FDM`

### Task 2: `mfg.print-3d-bed-size` rule

Compute the part's overall AABB (use `computePartBbox` from Phase 8). If any dimension exceeds 220mm × 220mm × 250mm, warn.

`convex/cad/validate/rules/print3dBedSize.ts`:

```ts
import type { CadIr } from "../../ir/types";
import type { Violation } from "../../../plugins/types";
import { computePartBbox } from "../../geometry/partBbox";

const DEFAULT_BED = { x: 220, y: 220, z: 250 };  // mm

export function print3dBedSize(original: CadIr): Violation[] {
  if (original.process !== "print_3d") return [];
  const bbox = computePartBbox(original);
  if (!bbox) return [];

  const dimX = bbox.maxX - bbox.minX;
  const dimY = bbox.maxY - bbox.minY;
  const dimZ = bbox.maxZ - bbox.minZ;

  const exceeds: string[] = [];
  if (dimX > DEFAULT_BED.x) exceeds.push(`X=${dimX.toFixed(1)}mm > ${DEFAULT_BED.x}mm`);
  if (dimY > DEFAULT_BED.y) exceeds.push(`Y=${dimY.toFixed(1)}mm > ${DEFAULT_BED.y}mm`);
  if (dimZ > DEFAULT_BED.z) exceeds.push(`Z=${dimZ.toFixed(1)}mm > ${DEFAULT_BED.z}mm`);
  if (exceeds.length === 0) return [];

  return [{
    ruleId: "mfg.print-3d-bed-size",
    severity: "warn",
    message: `Part bbox exceeds typical desktop printer bed (220×220×250mm): ${exceeds.join(", ")}.`,
    agentMessage: `This part is too big for an average i3-class FDM printer. Either split the part, scale it down, or rely on a larger printer (e.g. Voron 2.4 — 350×350×350mm).`,
  }];
}
```

Tests (3): part fits, part too big in X, part too tall.

Commit: `feat(cad-ir): mfg.print-3d-bed-size — warn when AABB > 220×220×250mm`

# CAD IR Phase 14 — Process-aware manufacturing rules

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development.

**Goal:** Add manufacturing rules that fire only for parts declaring specific processes. Phase 14 ships two rules for laser-cut / sheet-metal-bend processes: minimum slot width and minimum hole diameter (both ≥ material thickness, since the laser kerf can't cleanly cut narrower features). The agent gets process-specific feedback that mirrors what a real fabricator would reject.

**Why this slice:** Phase 3 added `mfg.hole-edge-distance` and Phase 5 added `mfg.min-bend-radius` — both apply universally. Real shops have process-specific limits the agent should hear: "this slot is too narrow for laser cutting," "this hole is smaller than the material is thick." Without these, the agent can produce IR that looks valid but won't actually be cut.

## Task 1: `mfg.laser-cut-min-hole` rule

**Files:** `convex/cad/validate/rules/laserCutMinHole.ts`, `__tests__/rules-laserCutMinHole.test.ts`

The rule: when `process === "laser_cut"` or `process === "sheet_metal_bend"`, every `hole` feature whose diameter is less than the part's material thickness (= the body's extrude distance) fails. Industry rule of thumb: laser kerf ≈ 0.1–0.3mm, can't cleanly cut a hole smaller than ~1× material thickness.

```ts
// convex/cad/validate/rules/laserCutMinHole.ts
import type { ResolvedIr } from "../../resolve/resolveIr";
import type { CadIr } from "../../ir/types";
import type { Violation } from "../../../plugins/types";

const PROCESSES_THAT_LASER_CUT = new Set(["laser_cut", "sheet_metal_bend"]);

export function laserCutMinHole(resolved: ResolvedIr, original: CadIr): Violation[] {
  if (!original.process || !PROCESSES_THAT_LASER_CUT.has(original.process)) return [];
  const out: Violation[] = [];

  // Find each extrude's distance (= material thickness) by feature id
  const extrudeThickness = new Map<string, number>();
  for (const f of resolved.features) {
    if (f.kind === "extrude" && !f.suppressed) {
      extrudeThickness.set(f.id, f.distance as number);
    }
  }

  for (const f of resolved.features) {
    if (f.kind !== "hole") continue;
    const thickness = extrudeThickness.get(f.face.feature);
    if (thickness === undefined) continue;
    const diameter = f.diameter as number;
    if (diameter < thickness) {
      out.push({
        ruleId: "mfg.laser-cut-min-hole",
        severity: "error",
        message: `Hole "${f.id}" diameter ${diameter}mm is below the material thickness ${thickness}mm; laser-cut kerf can't cleanly produce holes that small.`,
        agentMessage: `Hole "${f.id}" is too small for laser cutting. Either increase its diameter to at least ${thickness}mm, drill it as a separate post-process, or change the part's process to "cnc".`,
        location: { kind: "hole", id: f.id },
      });
    }
  }
  return out;
}
```

Note: this rule needs both the resolved IR (numeric values) and the original IR (for the `process` field which is a string, not resolved). The signature takes both.

## Task 2: `mfg.laser-cut-min-slot` rule

**Files:** `convex/cad/validate/rules/laserCutMinSlot.ts`, `__tests__/rules-laserCutMinSlot.test.ts`

A "slot" in the IR is a `cut_extrude` with a small rect sketch. Phase 14 v0 detects slots as `cut_extrude` features where the smaller of the rect's width/height is below material thickness. Limitation: only handles rect sketches; circular cuts and complex slot shapes are deferred.

```ts
// convex/cad/validate/rules/laserCutMinSlot.ts
import type { ResolvedIr } from "../../resolve/resolveIr";
import type { CadIr } from "../../ir/types";
import type { Violation } from "../../../plugins/types";

const PROCESSES_THAT_LASER_CUT = new Set(["laser_cut", "sheet_metal_bend"]);

export function laserCutMinSlot(resolved: ResolvedIr, original: CadIr): Violation[] {
  if (!original.process || !PROCESSES_THAT_LASER_CUT.has(original.process)) return [];
  const out: Violation[] = [];

  // Find each extrude's distance — the material thickness
  let thickness: number | undefined;
  for (const f of resolved.features) {
    if (f.kind === "extrude" && !f.suppressed) {
      thickness = f.distance as number;
      break;  // assume the first extrude defines the part's material thickness
    }
  }
  if (thickness === undefined) return [];

  for (const f of resolved.features) {
    if (f.kind !== "cut_extrude") continue;
    const sketch = resolved.sketches[f.profile];
    if (!sketch) continue;
    for (const g of sketch.geometry) {
      if (g.kind !== "rect") continue;
      const narrowest = Math.min(g.width, g.height);
      if (narrowest < thickness) {
        out.push({
          ruleId: "mfg.laser-cut-min-slot",
          severity: "error",
          message: `Slot in cut "${f.id}" is ${narrowest}mm wide; laser cutting requires slots ≥ material thickness (${thickness}mm).`,
          agentMessage: `The slot cut by feature "${f.id}" is too narrow (${narrowest}mm) for laser cutting in ${thickness}mm material. Widen the slot to at least ${thickness}mm or change the part's process to "cnc".`,
          location: { kind: "slot", id: f.id },
        });
        break;  // one violation per cut_extrude is sufficient
      }
    }
  }

  return out;
}
```

```ts
// convex/cad/validate/manufacturingTier.ts
import type { ResolvedIr } from "../resolve/resolveIr";
import type { CadIr } from "../ir/types";
import type { Violation } from "../../plugins/types";
import { holeEdgeDistance } from "./rules/holeEdgeDistance";
import { minWallThickness } from "./rules/minWallThickness";
import { boltClearance } from "./rules/boltClearance";
import { minBendRadius } from "./rules/minBendRadius";
import { laserCutMinHole } from "./rules/laserCutMinHole";

export function validateManufacturingTier(resolved: ResolvedIr, original: CadIr): Violation[] {
  return [
    ...holeEdgeDistance(resolved),
    ...minWallThickness(resolved),
    ...boltClearance(resolved),
    ...minBendRadius(resolved),
    ...laserCutMinHole(resolved, original),
    ...laserCutMinSlot(resolved, original),

}
```

## Out of scope for Phase 14 (deferred)

- **CNC tool-diameter rules** — minimum internal corner radius; needs tool-spec input. Future phase.
- **3D-print overhang detection** — needs feature-by-feature angle computation; complex.
- **3D-print min wall thickness per material** — currently global mfg.min-wall-thickness covers it generically.
- **Slot length / aspect ratio rules** — laser-cut slots have practical aspect-ratio limits.
- **Multi-process parts** — current model is one process per CadIr. Sub-parts can have different processes (which already works in Phase 9 inline parts).

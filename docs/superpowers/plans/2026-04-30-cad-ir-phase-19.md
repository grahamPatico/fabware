## Tasks

### Task 1: Mega-integration test

`convex/cad/__tests__/integration-final.test.ts`. The test builds an assembly that exercises:

- **Phase 1**: extrude with parametric expressions
- **Phase 2**: a `set_parameter` patch then `modify_feature` patch applied via the patch applier
- **Phase 3**: a hole with countersink (countersink subtype)
- **Phase 4**: multi-part assembly with revolute joint + bolt connection
- **Phase 5**: a part with a fillet
- **Phase 6**: an MJCF compile alongside URDF
- **Phase 7**: a sketch with a horizontal constraint
- **Phase 8**: a static AABB inter-part interference check (clean — no overlap)
- **Phase 9**: external part with vendor/partNumber for the BOM
- **Phase 10**: budget = $20; assert cost is under
- **Phase 11**: joint-range collision sampling (clean)
- **Phase 12**: declare `material: "aluminum-6061"` on parts; assert non-zero fabrication cost
- **Phase 13**: declare `process: "laser_cut"` on a part; assert non-zero machine cost
- **Phase 14**: laser-cut min-hole rule passes (hole d ≥ thickness)
- **Phase 15**: a sketch with a polygon entity
- **Phase 16**: print_3d part with material above min-wall threshold
- **Phase 17**: cnc part with cornerRadius ≥ tool radius (passes)
- **Phase 18**: external part with stepUrl

Then asserts:
- `validateSchemaTier`, `validateConstraintTier`, `validateAssemblyTier`, `validateManufacturingTier` all return only warnings (no errors)
- `compileToBuild123d`, `compileAssembly`, `compileToUrdf`, `compileToMjcf`, `compileBom`, `compileCost`, `compileFabricationCost`, `compileMachineCost` all produce non-empty output of the expected shape
- `cost.totalUsd` is finite, > 0, ≤ budget
- `hashIr` is deterministic

This is the longest test in the suite. It's deliberately the canonical "everything works together" sanity check.

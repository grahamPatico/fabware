## Executive Summary

The 19-phase CAD IR rebuild ships a **coherent, well-typed, well-tested IR/validate/codegen stack**. Internal API surfaces — five validation tiers, five compile targets (build123d / URDF / MJCF / BOM / cost), 12-tool patch grammar, process-gated MFG rules, joint sampler, AABB interference, STEP import codegen — are real, exported, and consume one another at the typecheck and unit-test layer. Every phase tip typechecks with **0 new errors** introduced by CAD IR work, and the per-phase Nyquist VALIDATION.md docs are uniformly compliant.

However, three integration gaps compromise the **milestone-level cutover gate**:

1. **`cadIrPlugin` is never registered.** It's invoked via a hardcoded `if (useCadIr)` fork in `orchestrator/tick.ts:85`, not through `_registerPlugin`. The plugin's `validate()` also skips Tier 3 (geometry runs only inside the specialist after sandbox execution).
2. **Four of the five compile targets are reachable only from tests.** The live specialist runtime invokes only `compileToBuild123d`. URDF, MJCF, BOM, cost, and `compileAssembly` are exercised exclusively in `integration-final.test.ts`. Phases 4/5/6/9/10/12/13 outputs never reach a query or surface.
3. **CUTOVER-02 (glTF preview parity) is broken end-to-end.** Sandbox emits a glb; nobody persists it (`sandboxResult.glb` is dropped, `glbStorageId` schema field is dead). `CadPreview.tsx` is an orphaned export imported nowhere in `src/`. `AssembledView`/`Workspace` have no `useCadIr` fork. There is no UI control to flip `useCadIr`.

A minor finding: `toolCallToPatch` for `add_part` silently drops `stepUrl`, so agent-authored STEP imports don't round-trip through the patch grammar even though `compileAssembly` handles them correctly when populated directly (EXTERNAL-01 partially affected).

## Recommended Closure Phases

Three closure items for the gaps identified:

1. **Phase 19.1 — Plugin registration & live compile pipeline** (closes plugin-registration FAIL and live-compile FAIL)
   - Register `cadIrPlugin` via `_registerPlugin` (introduce `kind: "cad_ir"` and update orchestrator dispatch).
   - Wire `compileAssembly`, `compileUrdf`, `compileMjcf`, `compileBom`, `compileCost`, `compileMachineCost` into the live specialist runtime so phases 4/5/6/9/10/12/13 outputs are persisted.
   - Move Tier 3 (geometry) into the plugin's `validate()` contract.

2. **Phase 19.2 — glTF preview parity & useCadIr UI** (closes CADIR-02 + CUTOVER-02 FAIL)
   - Persist `sandboxResult.glb` via the existing `glbStorageId` schema field.
   - Wire a Convex query exposing the glb URL.
   - Mount `CadPreview` into `Workspace`/`AssembledView` behind a `useCadIr` fork.
   - Add a UI control (toggle) to flip `useCadIr` per part or globally.

3. **Phase 19.3 — STEP-import patch round-trip** (closes EXTERNAL-01 partial)
   - Update `toolCallToPatch` add_part dispatcher (`cadIr.ts:147-159`) to forward `stepUrl`.
   - Add a unit test asserting agent-authored `add_part {stepUrl: ...}` round-trips through patch grammar to `compileAssembly`.
